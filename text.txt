
Команда / Флаг	Описание
opencode	Запуск интерактивного интерфейса (TUI) в текущей директории.
opencode run "..."	Выполнить один запрос без запуска TUI.
opencode -c /path/to/project	Запуск в конкретной директории проекта.
opencode auth login	Настроить API-ключи для провайдеров.
opencode session list	Показать список сохраненных сессий.
opencode run --help	Показать все доступные флаги для команды run.
